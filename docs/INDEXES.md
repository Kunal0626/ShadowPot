# Index measurements

Generated by `tools/bench_indexes.py`. **Do not edit by hand** -- re-run the tool.

Every index ShadowPot ships is here with the measurement that justified it, and every candidate that was rejected is here with the measurement that rejected it. An index is not free: it costs space, it costs write time on every insert, and it gives the planner another way to be wrong. "Index the foreign keys" is a habit, not a reason.

## Method

Each candidate was created **alone**, from the same baseline, then dropped. Creating all of them at once shows which index the planner picked but not what any one is worth, because a query that got faster might owe it to a different index created in the same pass. The timing is the **fastest** of several runs rather than the mean: the minimum is the run least disturbed by other processes, so it is the most reproducible statistic available on a machine that is also doing other things.

## How to reproduce

```bash
python3 tools/gen_sample_logs.py --out /tmp/bench-logs \
    --days 30 --sessions-per-day 350 --seed 7 --quiet
python3 -m shadowpot.ingest --db /tmp/bench.db /tmp/bench-logs --quiet
python3 tools/bench_indexes.py --db /tmp/bench.db
```
